Script primer overlay dingbat, not Unicode

Golic Vulcan is a joining / contextual modern script (plus handwriting and ceremonial calligraphy). Existing redistributable fonts overlay Latin / Windows-1252 code points. That is a dingbat mapping. Consoles and proper Unicode pipelines cannot treat this as a script.

  • gotavlu-zukitaun — modern standard script. Display face here: Iyik. Teaching extra: Golsu.
  • el’ru-kitaun — handwriting. Extra: Kitaun (vertical in native use).
  • vanu-tanaf-kitaun — ceremonial calligraphy. Extra: Tanaf (not Zun-compatible).
  • Dzhaleyl — ancient plant-themed teaching extra (kirshara lettering, Zavel’s FontForge face).

Key map · ä / U+00E4 / Alt+0228 = au · Iyik also maps extra au to capital W (Zun-incompatible) · Iyik is missing several ASCII capitals (B D F J K L M N P R V X), so overlay samples use lowercase keys that actually exist in the cmap.
