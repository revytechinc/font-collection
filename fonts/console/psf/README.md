# Console PSF2

Generated by `scripts/gen-psf.py` from Noto Sans Mono Regular and pIqaD qolqoS
using python3-fonttools and Pillow. 512 glyphs each. Valid PSF2 with Unicode
table (magic `72 b5 4a 86`).

| File | Geometry | Coverage |
|---|---|---|
| CloudBSD-Latn-8x16.psf | 8×16 | U+0000–U+00FF plus Esperanto Ext-A, Valyrian macrons, Ȳȳ, U+02BC |
| CloudBSD-Piqd-16x16.psf | 16×16 | Latin-1 from Noto + CSUR U+F8D0–U+F8FF from qolqoS |

Tengwar PSF: skipped (combining tehtar). Golic native: skipped. Atlantean native: not shipped.

Linux: `setfont CloudBSD-Latn-8x16.psf`  
FreeBSD vt(4): does not load PSF2 directly; `make install` copies these into `${PREFIX}/share/vt/fonts` for later `vtfontcvt(1)` / `vidcontrol(1)`. See README.md.

Rebuild: `make psf` from the repo root.
