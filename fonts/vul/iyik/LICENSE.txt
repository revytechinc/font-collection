> The last font is Iyik Vulkansu or Iyik for short. it means Modern Vulcan

Encoding: Latin / Windows-1252 overlay dingbat (same keys as Latin). There is
no Unicode / CSUR Golic block. Alt+0228 / U+00E4 (ä) is the “au” glyph.
Iyik also maps extra “au” to capital W (Zun-incompatible).

Zun is NOT redistributable and is NOT in this tree. Request Zun yourself
from skladan at korsaya.org. Do not vendor Zun.

WOFF2 here is a format conversion of the Original Version (woff2_compress).
No glyph edits. CSS family name “Iyik Vulkansu” is not an OFL reserved name.
